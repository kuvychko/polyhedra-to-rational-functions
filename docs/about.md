# About

A project by [Igor Kuvychko](https://www.linkedin.com/in/igor-kuvychko). The computations and renders use
[complexplorer](https://github.com/kuvychko/complexplorer), a library for visualizing complex
functions.

## Background

- Oliver Nash, [On Klein's Icosahedral Solution of the Quintic](https://arxiv.org/abs/1308.0955).
  Background for Klein's polyhedral invariants, which the original ornaments are built from.
- Elias Wegert, *Visual Complex Functions: An Introduction with Phase Portraits*. The source
  of the phase-portrait conventions used throughout.

No literature review has been done yet. Nothing here claims that the recipes are new.
